## 4. Пропуски, закрытия, особые часы

| Что | Объём | Комментарий |
| --- | --- | --- |
| Часов без единого входа (заполнены нулём) | 2.0% строк | MTA не публикует часы без входов; в основном ночь на малых станциях |
| Закрытые станционные дни (`is_closed`) | 1.65% строк | поток < 10% медианы станции за тот же год и день недели |
| Отрезков закрытий | 3 893 | у 307 станций |
| Сдвоенный час осеннего перевода времени | 3 ч | в 01:00 сложены два часа; фактически входов в ~1,3 раза больше соседних часов; флаг `is_dst_double_hour` |
| Весенний перевод времени | час 02:00 отсутствует | несуществующий час, не пропуск |

Закрытые дни не удаляются: при обучении их строки исключаются из целевой переменной, а лаги, попадающие на них, заменяются пропусками.

«Известен заранее» — признак доступен на момент прогноза без допущений.

| праздники | is_holiday, holiday_name, is_day_before/after_holiday, xmas_week | да |
| школа | is_school_day (официальные календари NYC Public Schools) | да |
| режимы | regime_student_omny, cp_active | да |

| погода (факт) | температура, осадки, снег, ветер и др.: город / сетка 0.1° / сетка 0.25° (Open-Meteo, ERA5) | нет — фактическая погода; используется для обучения |
| погода (прогноз) | те же переменные без snow_depth: прогноз, выпущенный за 24 ч (Open-Meteo Previous Runs), город / сетка 0.1°, с 2024 года | да — для оценки на val/test |
| станция | scale_weekday, commute_index, cluster, n_lines, in_cbd, borough, координаты, venue | да (по train) |

| закрытия вчера | closed_prev_day, closed_run_days, level_prev_day (доля обычного уровня вчера) | да: по спросу до конца вчерашнего дня и медиане прошлых 52 недель |
| закрытия (маска) | is_closed (по дням) | нет: флаг вычислен по фактическому спросу этого же дня — использовать только как маску (исключать из обучения и метрик), но не как входной признак, иначе утечка |

## 9. Прогноз погоды против фактической

Прогноз выпущен за 24 ч до часа (Open-Meteo Previous Runs, переменные `*_previous_day1`), точка Центральный парк. Обучение — на фактической погоде, оценка на val/test — на прогнозной; разница в ошибке модели показывает цену допущения «идеальный прогноз погоды».
